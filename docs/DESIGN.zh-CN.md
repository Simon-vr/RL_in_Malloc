# 设计、假设与局限

本文记录有意的设计选择、代码中不显眼的假设，以及当前方法的已知局限。建议与
[`METHOD.zh-CN.md`](METHOD.zh-CN.md) 一起阅读。

## 1. 为什么用候选集 —— 以及由此产生的不对称

每一步环境只把满足请求、按起始地址排序的前 `k = 5` 个空闲块交给智能体，由它
在其中选择。这让动作空间小而固定（`k` 个离散动作），从而可以用一个小网络。

代价是刻意接受的：**启发式基线会扫描所有空闲块**，因此它们的有效动作空间严格
大于 DQN。特别是 Best-Fit 的全局最优块常常**不在** DQN 的候选集里，于是 DQN
**无法表达**那个让 Best-Fit 强的选择。这很可能是学到的策略无法超过 Best-Fit 的
最主要原因（见[第 8 节](#8-已知局限)）。

## 2. 奖励设计：HHI 是代理目标

奖励是空闲份额的 HHI，即空闲字节在多大程度上集中在少数大块。其理由是大块集中
的空闲链表更容易满足未来（包括较大的）请求，因此与低外部碎片相关。

这只是**代理**指标，而非评估目标。我们*评估*的是占用率、时长、
碎片率。最大化一个平滑的集中度代理，并不保证占用率最优——实测也确实如此
（DQN 的占用率低于 Best-Fit）。

## 3. HHI：唯一定义

HHI 只定义一次，位于 `rlmalloc/metrics.py`：

```
HHI = Σ(lᵢ / S_total)²      对轮末空闲块求和
```

* **范围**：`N` 个空闲块时 `1/N ≤ HHI ≤ 1`。单个空闲块 → `HHI = 1`；`N` 个等大
  块 → `HHI = 1/N`；没有空闲 → `HHI = 0`。
* **方向**：越高越健康（空闲块更少、更大）。
* **上界**：对份额 `sᵢ = lᵢ/S_total`，有 `Σ sᵢ² ≤ maxᵢ sᵢ · Σ sᵢ = maxᵢ sᵢ`，
  而 `maxᵢ sᵢ = 1 − Fragmentation`，故恒有 `HHI ≤ 1 − Fragmentation`。因此高
  HHI 必然意味着低碎片。
* **为什么 Worst-Fit 的 HHI 最低**：Worst-Fit 总是从最大块分配，会逐渐把空闲
  链表"摊平"成许多大小相近的中等块（最大份额约 0.13，而 First/Best-Fit 约
  0.34–0.37）。份额越接近相等，`Σ sᵢ²` 越小，故 Worst-Fit 最低。

奖励使用的就是这个量；不存在第二个"补"指标。

## 4. 非法动作会终止回合

若智能体选出候选集之外的索引，回合立即以奖励 `-1.0` 结束。这抑制了非法选择，但
在训练早期（`epsilon` 高）大量随机动作都是非法的，导致回合很短、学习从一个大多
为负的信号开始。这是当前设计下的预期行为，不是 bug。

## 5. 评估负载语义

评估负载基于**乐观参考时间线**生成：假定每次分配都成功，因此每个 `free` 事件
引用的分配序号在该参考路径上必然存活。提前失败的策略会在到达后续 free 事件前
停下。同一轮中所有策略回放完全相同的事件列表，因此对比是配对的。

free 事件引用**分配序号**（第 n 次成功分配），而非原始地址；这消除了早期"随机
free id 可能指向从未发生的分配、被静默忽略"的失效模式。

## 6. 属于"选择"而非"推导"的超参数

以下均为手工选择，**没有**系统调参：

| 参数 | 取值 | 说明 |
|---|---|---|
| 学习率 | `1e-4` | Adam |
| ε 方案 | `1.0 → 0.01`，每回合乘 `0.999` | |
| 回合数 | `10000` | |
| `LEARN_EVERY` | `1` | 梯度更新节奏（速度旋钮） |
| `MAX_STEPS_PER_EPISODE` | `2000` | 安全上限 |
| 双峰 σ | `0.9` | 70% / 30% 混合 |

由于这些未做搜索、且只用了单一种子，较小的指标差距（如 DQN 与 First-Fit）
可能并不具有统计意义。

## 7. 设备与确定性

训练默认 CPU（`--device cpu` 或 `RLMALLOC_DEVICE`），以便固定种子时可复现；GPU
训练为可选项。完整参考运行使用 NVIDIA RTX 5060 Laptop GPU。

## 8. 已知局限

1. **动作空间受限** —— 只有前 `k` 个候选，无法表达 Best-Fit 的全局选择
   （[第 1 节](#1-为什么用候选集--以及由此产生的不对称)）。
2. **代理奖励** —— 优化 HHI，而非占用率/时长/碎片率。
3. **可观测性有限** —— 没有全局空闲链表统计或历史。
4. **分布偏移** —— 只在一个负载上训练，另外三个是分布外。
5. **单一种子、无误差棒** —— 小差距可能是噪声。
6. **早期探索代价高** —— 非法动作即结束回合。

净效果：智能体明显强于 Worst-Fit，但不超过 Best-Fit，且大致只与 First-Fit 持平。

## 9. 未来工作

* 拓宽或重构动作空间（例如把 best-fit 块纳入候选，或采用指针式 / 因子化动作
  表示），让智能体能表达强启发式的选择。
* 把奖励塑形或替换为更贴近评估目标（占用率、时长）的形式，同时保持稳定。
* 增加更丰富的状态特征（空闲块数量、总空闲字节、最大空闲块、近期请求统计、
  时序上下文）。
* 在混合分布上训练并衡量迁移。
* 跑多种子并报告 mean ± std；扫描学习率与 ε 方案。
* 与一个"best-fit oracle"对比，以分离候选集限制带来的代价。
